# Provenance

The implementations, grammar specifications, examples, diagrams, and reports
were created or adapted by the repository owner as university assignments. The
Russian-language reports are the student's original submission artifacts; code
inside those reports is a historical snapshot.

The following material has a separate provenance:

- `lab1-1` contains a supplied P5 Pascal compiler/toolchain that was modified
  for the assignment. Its Pascal sources are treated as vendored code.
- `lab2-2/sample/parser_edsl.py` and `lab3-3/sample/parser_edsl.py` are identical
  copies of the parser EDSL used as course support infrastructure. They are
  treated as vendored; the lab-specific grammar and semantic code in `main.py`
  remains project work.
- Flex and Bison outputs are generated during out-of-source builds and are not
  committed.
- `lab1-1/iso7185.pdf` is a 2005 scan credited in its metadata to Scott Moore.
  Redistribution permission has not been established. It remains as a
  historical course-bundle artifact pending an owner decision; removing the
  working-tree copy would not remove it from Git history.

Because these components do not share a confirmed licensing basis, no
repository-wide license is asserted. Before redistributing supplied files or
adding a blanket license, confirm their original terms.
